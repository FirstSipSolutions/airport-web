## User Stories

### Airports

- As a user, I can view a list of all airports so that I can see which airports are in the system.
- As a user, I can add a new airport with a name, code, and city so that the system reflects newly served locations.
- As a user, I can edit an existing airport so that I can correct details without recreating the record.
- As a user, I can delete an airport so that closed or incorrect entries are removed.

### Cities

- As a user, I can view all cities with their province and population so that I have context for the airports they contain.
- As a user, I can add, edit, and delete cities so that airport locations stay accurate.

### Aircraft

- As a user, I can view all aircraft with their type, airline, and passenger capacity so that I can see the available fleet.
- As a user, I can add, edit, and delete aircraft so that the fleet record stays current.

### Passengers

- As a user, I can view all passengers with their contact details and home city so that I can look up traveller information.
- As a user, I can add, edit, and delete passengers so that records stay accurate.

### Across the app

- As a user, I see a loading indicator while data is being fetched so that I know the page is working.
- As a user, I see a clear error message when the API is unavailable so that I'm not left with a blank screen.
- As a user, I can navigate between sections using the top navigation so that I can move around without editing the URL.
